# Front Windows Preview

这是未签名的 Windows x64 测试包，不是 v0.7 正式发布。签名更新底座已经实现，但当前包没有正式信任公钥，自动更新默认禁用；Commit、PR或测试附件不会向普通用户推送更新。

安装版使用系统用户数据目录（`%LOCALAPPDATA%/io.github.fiesty-abyss.front`），程序与资料分离。便携版解压后打开 `Front.exe`；同目录的 `Front.portable` 标记启用独立 `FrontData`。请完整保留 `backend` 文件夹，不要只复制 EXE。只读目录会停止启动，移动至可写目录后重试；不会重置数据库。

有经验的用户可通过 `FRONT_DATA_DIR` 自定义数据目录；普通运行无需手动安装Python、Node或Rust，也不要求配置AI推理服务或专用GPU。WebView2使用Windows已安装的运行时；安装包在缺少时引导下载微软运行时，便携包目前要求系统已有WebView2。完整离线运行时包后续提供。

首次运行自动创建资料库。已有资料升级前检查结构，发现未知未来结构拒绝降级；有迁移时生成完整备份并在隔离目录验证恢复，再沿用Web版迁移逻辑。缺失托管素材或备份验证失败会阻止默认升级，请在Web版检查备份报告。外部原地索引文件默认只保存路径引用。

关闭窗口会停止本窗口拥有的后台服务，强制结束窗口进程也会通过Windows Job Object关闭所属Sidecar。不会停止已运行的Web版或AI服务。不启动SD/ComfyUI/Ollama，不扫描私人目录。摄像头和模型推理不会自动启动。

日志位于资料目录的 `logs/desktop.log`，仅记录生命周期和错误类型，轮转限制1MiB×4，不写API Key或访问日志。WebView缓存位于该资料目录的 `webview`。私人数据、模型、密钥不属于安装包构建输入。

默认升级流程保留用户数据；卸载器的数据删除选项须由用户明确选择。删除便携目录前自行保管其中FrontData。恢复完整备份先在隔离目录校验，不能覆盖运行中的数据库。当前不提供程序内无缝切换数据目录；真实更新安装、失败后程序恢复及干净系统安装升级尚未验收，不能将更新底座或测试签名当作正式更新上线。

依赖来源：Tauri官方CLI/Rust库（MIT/Apache-2.0），PyInstaller官方发行（GPL及打包例外）；应用依赖的声明与可用许可证文本随 `backend/licenses`、`THIRD_PARTY_NOTICES.json` 提供。公开正式发布前仍需完成依赖和安装器验收、代码签名与更新签名，不携带任何Live2D专有SDK或第三方模型。

预览验收边界：安装器已构建，尚未完成干净系统安装/卸载/升级矩阵；原生窗口、生成音频索引/播放、正常退出、强制终止外壳后的后端清理及资料保留已在本机验收。真实Windows ACL拒绝的源/冻结检查已经通过；这不能替代真实只读磁盘、缺失WebView2或安装中断验收。详细状态见仓库 docs/WINDOWS_DESKTOP.md 与 docs/RELEASE_CANDIDATE_STATUS.md。

## 下载检查与安装

仅从对应GitHub Actions成功运行下载内部附件；它不是公开稳定Release。解压外层Artifact，用系统Get-FileHash -Algorithm SHA256核对SHA256SUMS.txt。BUILD_MANIFEST.json记录版本、40位源提交、平台、未签名与未验收安装状态。Hash用于检测损坏，不能替代发行签名和来源审查。

安装版运行同一附件中的x64安装器，程序文件与用户资料分离。便携版将内层ZIP完整解压到可写目录，再打开Front.exe；不要从ZIP预览中运行，不能覆盖运行中的EXE。缺少WebView2或网络不通时，保留资料，在具备微软运行时的环境重试；不要为测试移除系统运行时或关闭Windows防护。

## 替换预览版与恢复

1. 关闭使用同一资料目录的Web和Desktop，另存完整备份并在独立目录验证恢复。外部索引默认仅保留引用，应另行保护原件。
2. 便携新版解压到全新目录。确认旧FrontData备份可恢复，再由用户决定复制到新目录或通过FRONT_DATA_DIR引用独立资料目录。不要整个覆盖旧程序，不复制运行中的SQLite/WAL。
3. 安装升级沿用分离的用户资料目录；兼容失败停止，不能删除数据库继续。安装故障先保留资料/备份，在独立目录验证程序，不把新版库交给旧版写入。
4. 卸载通过Windows应用列表进行，不选择删除个人资料；重装前核对资料目录。删除整个便携目录会删除其中FrontData，必须先备份或迁出。此说明尚需干净VM实操，不代表已验证卸载器全部行为。

Web默认数据位置由FRONT_DATA_DIR或Web配置决定，与便携FrontData不自动合并；在总览/设置核对实际目录。不要同时启动Web和Desktop写同一库，不将私人数据库、模型或Key放进程序包。
