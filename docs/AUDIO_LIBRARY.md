# Audio Library：复用素材库的音声收藏

2026-10-24。新增懒加载 `/audio`；媒体仍属于Asset与现有文件系统，不建立第二份文件仓库。

## 本阶段

- 自定义收藏类型、专辑/播放列表、封面引用、全局标签、收藏/星级/喜爱度、备注，以及世界观/作品/角色稳定ID关联。音轨从现有素材选择或导入，单文件可在多个播放列表出现。
- 继续TinyTag提取标题/艺术家/专辑/作者相关标签、时长、采样率/码率/位深/曲目/封面。未知保留空，容器扩展名与具体编码区别显示，不编造作品来源。超大ID3标签降级读取。
- 目录预览、增量指纹和索引继续复用projectpreview/index_file/ingest_stream；新library_imports仅编排可恢复任务，逐项提交，取消/重启后继续未完成项。新内容作为新素材，旧索引保留并报告原件变化，不覆盖历史档案。
- 一个可见播放器、Range流式文件、5秒/暂停续听、倍速/循环、书签及笔记；内容换版需明确确认，旧书签带源Hash。页面退出停止音轨/移除源，保存采用并发版本与源身份保护。
- LRC/SRT/VTT以素材引用关联，限2MiB/10000字幕，转为本地VTT；不转录、不调用AI。PCM WAV波形按需有限任务，分512区间各采样至多256帧，不是完整峰值分析。
- 浏览器不能解码或原路径变化时提示；不偷偷转码，不上传音频。压缩音频波形和可选转码为后续事项。

## 真实验证范围

自动化专题6项：续听并发/ID复用保护、音轨多集合引用、字幕转换、Range206、波形、目录增量/去重/换版、取消后继续单个未完成项、完整备份与隔离恢复保留专辑和进度。最终全量210项后端测试与生产构建通过。

本机已有FFmpeg仅用于在Front `.cache` 生成24秒440Hz音调及标签；没有使用任何用户音频或WebUI工具。WAV/MP3/FLAC/OGG/M4A实际导入并在浏览器播放：readyState=4、时间前进、无MediaError。续听重开恢复约8.51秒及1.5倍速、书签和LRC真实显示，PCM波形实际任务通过；不是Mock，也不保证所有同容器编码均能解码。

1440px与390px交互验收；窄屏最初发现内部main样式重名，修正后文档宽380px，无横向溢出，控制台错误0。截图仅生成测试样本。

## 性能与兼容

独立生成10万条元数据（不是10万个真实音频文件），末页50条十次请求中位8.64ms、最大54.25ms；标题查询命中10条约137.61ms，响应2933字节。热缓存、当前本机，不等同冷盘/网络盘/真实解码压力。音轨查询只取当页元数据，不读取音频原件。

新增audio_albums/audio_states/library_imports/library_import_items及标签关联表，纯加表，不批量迁移历史用户资料。完整备份包含这些行；索引音频默认只保存外部引用，用户明确选择才复制进备份。AudioLibrary独立JS13.40kB（gzip5.55kB）、播放器10.67kB（gzip4.94kB）、共享导入面板6.29kB（gzip3.25kB）按需加载；入口gzip80.52→80.67kB。没有新产品依赖，不捆绑测试用FFmpeg；波形及字幕按需处理。桌面生命周期和安装包在后续独立PR。
