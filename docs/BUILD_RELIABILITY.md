## 改动

现有Windows构建步骤在同一desktop工作目录调用`bundle_retry.py`，仍执行完全相同的`npm run build -- --ci -- --locked`。只在Tauri明确报告打包HTTP502/503/504，且最近下载来自官方tauri-apps/binary-releases或nsis-tauri-utils GitHub Release路径时最多重试两次（5秒、15秒等待）。

编译/证书/签名/Hash错误、401/404/429/500、其他来源或无下载证据不重试。未切换镜像、URL、锁文件或信任根；Tauri自己的下载校验及后续独立CRC/SHA256/清单检查保留。最终失败仍返回非零，Artifact仍只在后续所有步骤成功时上传；不发布Release。持久上游故障无法由重试保证解决，三次失败就停止，不重跑整套CI到无限。

构建输出实时透传，诊断只保留最后64KiB在内存。它仅用于开发CI，不进入应用业务启动链，不启后端、摄像头/GPU或推理，也不改数据目录/个人安装。
