# 角色卡创作工作台

本增量增强既有 `/cards`，不新建人物、素材或生图引擎。手动编辑在没有AI服务时完整可用；真实模型生成质量尚未验收。

## 已实现

- 每页20项摘要与名称/标签/设计别名搜索；正文和自定义扩展只在选择后读取。沿用现有FTS，保存/导入/恢复时更新索引，不自动重建个人旧库。已有外部扩展的历史索引可由用户显式重建。
- 空白、角色对话和剧情模板；已有百科/OC创建独立草稿，保留稳定人物/世界观/作品来源。两个世界观的同名人物不会按名字合并。独立人物不强制关联世界观。
- 介绍、性格、场景、开场、示例、System Prompt、备用开场和自定义扩展；`front_design_v1`保存别名、外貌/服装/发型/瞳色、收藏、0–5星级、0–100喜爱度及备注。未知未来扩展保留并禁用不兼容的设计控件。
- 只选择现有Asset封面，复用缩略图与原地索引；世界书候选限全局或所属世界观。已有小说抽取/证据审核入口继续复用：审核入百科后可创建草稿，不新增未经审核的自动小说解析。
- 服务端身份/范围指纹、事务写入、过期草稿409；不可变版本和恢复追加。版本恢复前校验当前人物/世界观/世界书范围。原百科/OC/小说不被角色卡修改。
- V1/V2/V3字段导入、V2 JSON/PNG导出。16MiB输入、1MiB JSON、1600万像素及单图像操作限流。PNG导入封面复用Asset去重；外部卡的本地ID不自动绑定。原地封面导出验证Hash，不用空白图静默替代失效资源。

## AI辅助：先预览、后审核、再保存

只使用用户明确选定的已配置文本服务，无隐式环境变量服务。预览显示完整消息、模型/地址、温度和2048 token输出预算；仅发送本次手填说明和风格，不自动附带当前卡、小说、世界书、目录或图片。非字面回环端点需额外确认。准备指纹绑定配置、消息及凭据身份，改变后须重新预览。

复用现有2 worker / 32等待队列；超时上限60秒、结构化结果64KiB上限，不自动重试、启动服务或下载模型。取消是协作式：已发出的请求可能已被处理/计费，取消后不采用结果。重启标为interrupted，不重放远程调用。失败不保存原始异常或密钥。

独立 `CharacterCardDraft` 表持久化候选、服务快照、输入Hash/长度、任务状态和采用记录。候选逐字段放入未保存表单，再由用户保存采用；重复请求/采用保持幂等。已采用候选可只读查看，不覆盖后来编辑或恢复的版本。表内包含生成结果，应作为私人资料随数据库快照保护，不发布。

## 兼容与范围

只新增一张业务表，沿用升级前一致性备份、版本/完整备份恢复；没有大型依赖。旧CRUD路径保留并增加无效字段/引用检查；外部旧客户端的普通PATCH仍保留原兼容行为，新的工作台使用带指纹的reviewed-save。

未实现：自动封面生成专用流程（现有OC/出图入口保留）、小说原文直接转卡的新界面、完整第三方卡生态互通认证、模板自定义管理、多造型完整编辑、多模式聊天。这些不因存在入口而标为完成。
