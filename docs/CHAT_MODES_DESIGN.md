# 多角色与剧情：实现约束（未实现）

本文件是后续实现合同，**不是已上线能力或Mock演示**。依赖#66完成真实GUI、最新主线集成与全部CI后再开独立代码增量。本轮只收敛单人模型Draft和独立ISBN API，不创建群聊/剧情表、路由或页面。

## 数据与身份

复用ChatSession/ChatMessage及现有parent_id消息树、CharacterCard、Lorebook、Provider、版本和完整备份。旧会话默认solo，旧客户端字段兼容；新mode明确solo/group/narrative/choice。只有真正需要时才加参与者版本、有限轮次计划、剧情状态或记忆版本，不复制对话正文到第二套聊天库。

参与者使用稳定自身ID、角色卡ID及创建身份/版本指纹，具有昵称/头像引用、发言颜色、角色职能与启用状态；世界观使用稳定ID。修改/退出/加入追加版本，历史回复冻结原身份。角色删除或ID复用、世界观归属变化时新生成需人工重新绑定，不能按同名自动合并或回退其他角色。历史可看快照标签，缺失头像回退占位，不自动请求外站图片。

每位发言者选择自己的已配置Provider、模型、温度、输出及上下文预算与版本指纹。服务删除/换地址/能力变更阻止新生成，不静默换服务；密钥仍从当前安全设置读取，不放进快照/日志/导出。全局模型默认改变不改已绑定参与者、正式人物卡或旧回复。

## 上下文与轮次

每次生成只给当前发言者自己的角色卡/世界书/身份与必要的共享会话历史；其他角色的私有人设不能直接拼进它的system。共享设定和逐角色私有设定分开列入发送预览，不同远程服务的文本范围须明确确认。跨世界观会话需显式配置，不改变正式世界观/人物归属。

先交付手动指定发言者（包括@明确角色和旁白），再有限轮流调度，最后才做AI推荐发言者。推荐只是一项可审核建议，不自动开启无限互答。限制参与者数量、轮次数、每句输出、全局输出预算、排队/等待与总轮次截止；沿用现有单会话互斥和全局最多2生成。停止、离开或网络断开后不自动重放收费请求，保留已完成回复、部分输出和明确失败状态。

持久轮次计划记录显式请求ID/当前片段/已完成消息ID，不另造无限生成队列；长任务如采用jobs，只用现有有限队列。恢复必须重新检查绑定、取消标记和未完成请求，不再生成已确认完成的句子。调度期间拒绝同时修改角色绑定/模型或用expected版本返回冲突，不能一半轮次静默换人设。

上下文字数并非真实token窗口。未配置可靠计数/费率的服务不把估算叫作实际货币上限；不能保证费用预算时不启用有费用承诺的自动模式，只允许明确单轮调用。模型计数/usage与适配器参数支持必须真实核实，不猜测所有Provider都支持相同采样字段。无需启动Ollama/本地推理或支付服务即可管理参与者与历史。

每条回复沿用消息树保存发言者创建身份/卡片版本、Provider/模型/实际参数、上下文摘要及SHA256/计数、生成状态/消息版本、parent/head。上下文摘要标明人工/模型来源，不为日志再复制全部私人原文。生成完成只移动预期head；用户已切换分支或删除会话时不抢回head，不写孤儿回复。

## 剧情、选项和记忆

叙事/选项是独立mode，不改变solo/group已有行为。场景、章节、用户身份、关系/情绪/关键事件/已知信息属于本会话或明确派生创作版本。AI状态/记忆建议按配置审核，默认不写人物百科、原世界观或原小说。长期记忆可查看/编辑/删除/追加恢复，保留来源消息和分支，不无限塞全部历史。

剧情节点引用已有消息/分支和状态快照，不另存一份正文树。选项有稳定ID与版本、来源节点和原始生成证据；点击或自由输入都创建新分支行动，带请求幂等键和expected head。重选旧节点创建另一子分支，不覆盖旧路线。修改选项文字追加版本，旧选择保留当时文本；比较通过现有树的共同祖先和差异实现。

删除记忆的当前投影、保留历史回滚及真正移除敏感历史是不同操作，需清楚显示范围与保留策略，不能宣称删掉当前条目就删除了所有旧快照/备份。故事状态恢复不能默认回写正式设定。

图片、音乐只引用现有Asset，外部缺失可诊断，无需复制原件。Voice/OC/Live2D联动独立按需，默认不启动音频合成、图像推理、摄像头或渲染。导出只含用户明确选择的消息/设定/引用；导入做格式/大小/身份校验，不能携带可执行脚本/外部服务凭据或直接覆盖同名人物。
