# 支持的文件格式

v0.6.1 起，素材库除了图片和小说正文，还能识别下面这些文件。上传或批量导入时，后端（`backend/front_api/filetypes/`）先按扩展名和文件头判断类型，再读出信息、生成封面；前端（`frontend/src/viewers/`）负责预览。

- 识别出的类型**优先于**上传时手选的类型（比如把 `.vrm` 选成“参考图”上传，仍会存为 3D 模型）。
- 读出的信息存在素材的 `meta.file` 里；读取规则更新后，可以在详情里点“重新识别”（`POST /api/assets/{id}/reanalyze`），或一次重识别全部（`POST /api/assets/reanalyze`）。
- 所有文件都**只读**：Front 不修改、不转换你的原文件。

| 类型 | 扩展名 | 读出的信息 | 预览 |
| --- | --- | --- | --- |
| 3D 模型 | `.glb` `.gltf` `.vrm` `.obj` `.fbx` `.pmx` `.pmd` | 格式、顶点 / 三角面、网格 / 材质 / 节点数、生成工具、扩展；VRM 0.x / 1.0 的名称、作者、版本、**使用许可**（谁可以扮演、商用、再分发、修改、署名）和内嵌缩略图；PMX 的模型名（中 / 英）、注释、骨骼数、材质与贴图列表；PMD 的模型名与注释；FBX 的二进制 / 文本与版本 | three.js：拖动旋转、自动旋转、线框、深 / 浅背景、复位、播放内置动画；“设为封面”把当前画面存为缩略图。PMD 与 7.0 以前的 FBX 只显示信息 |
| Live2D | 含 `*.model3.json`（Cubism 3–5）或 `model.json`（Cubism 2）的文件夹 / zip，单独的 `.moc3` `.moc` | Cubism 版本（由 moc3 文件头判断：3.0 / 3.3 / 4.0 / 4.2 / 5.0 / 5.3）、moc 文件、贴图、动作组与数量、表情、物理、姿势、缺失文件 | 贴图缩略图、动作与表情列表。**不做实时渲染**：那需要 Live2D 官方的 Cubism Core，它是专有许可，Front 不附带也不下载 |
| 音频 | `.mp3` `.flac` `.ogg` `.oga` `.opus` `.m4a` `.aac` `.wav` `.aif(f)` `.wma` | 标题、艺术家、专辑、流派、年份、曲目 / 碟号、时长、码率、采样率、声道，内嵌封面（作为缩略图） | 内置播放器（封面、进度、音量、下载） |
| 视频 | `.mp4` `.webm` `.mkv` `.mov` `.m4v` `.avi` `.wmv` `.flv` | 时长、分辨率、帧率、视频 / 音频编码、码率、标题 | 浏览器能播放的格式直接播放；自动截取一帧作为封面。**需要本机装有 FFmpeg**（`ffprobe` / `ffmpeg` 在 PATH 中），没有时只记录文件信息 |
| PDF | `.pdf` | 页数、标题、作者、主题、创建工具、创建时间、页面尺寸；正文文字进入全文检索 | 逐页渲染（`GET /api/assets/{id}/pdf/{page}?width=`），首页作为封面 |
| 文档 | `.docx` `.xlsx` `.pptx` `.odt` `.ods` `.odp` `.epub`；`.doc` `.xls` `.ppt` `.rtf` | 标题、作者、创建 / 修改时间、工作表 / 幻灯片 / 章节数；正文文字进入全文检索 | Word / ODT / EPUB 显示标题层级与段落；Excel / ODS 显示前几张表的表格；PPT / ODP 显示每页的文字卡片。旧版二进制格式与 RTF 只记录文件信息 |
| 压缩包 | `.zip` `.tar` `.tgz` `.gz` `.bz2` `.xz`；`.7z` `.rar` | zip / tar 的文件数、总大小、目录（最多列 400 项，含旧版日文 / 中文文件名的编码修正）；7z / rar 只按文件头识别 | 目录列表；包里的图片可以直接打开查看 |
| 代码 / 脚本 / 文本 | `.py` `.js` `.ts` `.vue` `.json` `.yaml` `.toml` `.ini` `.lua` `.cs` `.cpp` `.glsl` `.sql` `.srt` `.ass` `.lrc` `.rpy` `.ks` `.tjs` 等 | 语言、行数（自动识别 UTF-8 / GBK / Shift_JIS 等编码读入）；Ren'Py（`.rpy`）、KiriKiri（`.ks`）、TJS、字幕、歌词会标出类型 | 带行号的语法高亮（highlight.js）。超过 2 MB 只读前 2 MB |

## 模型文件夹（整包）

Live2D、PMX（模型 + 贴图）、glTF（`.gltf` + `.bin` + 贴图）、OBJ（`.obj` + `.mtl` + 贴图）往往是一整个文件夹。

- **批量导入**扫描时会把这样的文件夹认成一个条目（预览里标为“模型包”），导入时打包成**一个 zip 素材**。单个包的上限是 512 MB。
- 也可以自己把文件夹压成 zip 再上传，效果一样。
- 预览时通过 `GET /api/assets/{id}/entry/{包内路径}` 按需读取包里的单个文件，**不会解压到硬盘**。包内路径只在 zip 自己的目录里查找（不区分大小写），不能访问包外文件；单个文件解压后超过 64 MB 不读，防止压缩炸弹。

## 封面

- 图片：自动生成缩略图。
- 音频封面、VRM 缩略图、视频截帧、PDF 首页、压缩包里的第一张图：识别时自动生成。
- 3D 模型可在预览里点“设为封面”；也可以给任何素材上传自定义封面（`PUT /api/assets/{id}/thumb`，只接受图片）。自定义封面在“重新识别”时会保留。

## 许可与边界

- 3D 预览使用 three.js（MIT）与 @pixiv/three-vrm（MIT）；PMX 读取是按公开格式说明自己实现的，只读静态网格、材质和贴图，不做骨骼动画与物理。
- 音频标签用 tinytag（MIT），PDF 渲染用 pypdfium2（Apache-2.0 / BSD-3-Clause）。FFmpeg 只在本机已安装时调用，不随 Front 分发。
- Live2D 只解析公开的 JSON 结构；Front 不包含 Cubism SDK 的任何部分。
- 识别出的作者、许可等信息只是展示文件里写的内容，是否允许使用以原作者的条款为准。
