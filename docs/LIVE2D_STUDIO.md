# Live2D Studio：档案阶段

当前提供独立工作区 `/live2d`，用于只读扫描与档案管理。**实时渲染、动作播放、面捕、道具、方案及工程编辑尚未实现。** 界面明确显示档案模式，不用静态贴图冒充实时模型。

## 使用

1. 进入 Live2D Studio → 扫描本地模型，输入运行 Front 的电脑上的文件夹或 ZIP 路径。Windows 可使用系统自带 tar 扫描 RAR，无需另装常驻服务。
2. 填写创作者、来源链接与许可说明；同一包发现多个 `.model3.json` 时分别登记。许可来自用户提供的信息，扫描不会自动推断作者授权。
3. 查看 moc3 文件头、声明的纹理/动作/音频/表情/物理/姿态/显示信息/用户数据引用，以及缺失文件、不安全路径、大小写不一致、配置异常等诊断。
4. 可编辑名称、模型版本、收藏、0–5 星、0–100 喜爱度、独立档案标签与备注；重新扫描保留这些资料。移除档案仅删除档案记录，原始模型文件保留。

模型仅登记原始目录/压缩包与相对路径，不提取、不复制、不覆盖。文件夹从不同父目录重复扫描，通过实际 model3 路径识别同一模型；ZIP/RAR 按包路径和条目区分。列表分页，诊断 JSON 仅详情读取。前端路由按需加载，无 Cubism/MediaPipe 新依赖、WebGL 场景或摄像头请求。

## 诊断范围

- 扫描 `.model3.json` 的声明依赖，并列出邻近的动作、表情、物理、姿态及 VTube Studio 配置。邻近文件不代表模型已声明、可播放或归属于该模型。
- 参数来自 CDI、动作、表情和模型 Groups 引用；不是 Cubism Core 枚举，缺少参数范围、默认值与完整性保证，不能直接作为通用面捕映射。
- 文件存在不代表纹理/音频内容有效；moc3 头信息不代表模型二进制完整、版本兼容或可渲染。所有结果保留 `runtime_verified=false`。
- 只支持 Cubism 3+ 档案扫描；旧素材预览器的 Cubism 2 信息识别保留。RAR 为 Windows 可选能力，其他平台请提供 ZIP/文件夹。密码包、编码异常、损坏包会报告错误。
- 限额：每包 20000 文件、每次 100 模型/100 压缩包、每份 JSON 2 MiB；RAR 子进程输出有界，单次调用 20 秒超时，不执行包中代码。当前不验证全部压缩包 CRC、图片内容与任意复杂文件的最坏资源消耗。
- 来源移动后原路径检查返回具体缺失错误；尚无自动追踪移动、重定位向导或内容哈希合并模型档案。
- 标签与评分目前仅属于 Live2D 档案，尚未与全局素材/收藏集统一；没有浏览器 ZIP 上传、方案导出或外部编辑器打开接口。

## 真实素材与生成样本

2026-10-18 在本机 Windows 实际只读扫描用户提供的三个 RAR 和两份说明，识别 3 个模型；声明依赖共 24 项，未发现缺失。扫描前后原始文件 SHA256 一致。私有详细报告与档案留在 `.cache/live2d-private-verification.json`、`.cache/live2d-private-data/`，不提交 Git。

第二次独立验证包含应用初始化、API 后台任务与档案写入，耗时约 0.747 秒，tracemalloc Python 峰值 5,852,269 bytes；首次约 0.728 秒、6,404,693 bytes。两次都不是 GPU、渲染 FPS、服务独立 RSS 或长时间泄漏测试。真实模型尚未渲染或播放动作。

## 许可与发布前置

截至本次查阅，[官方 Web SDK 下载](https://www.live2d.com/en/sdk/download/web/)要求阅读并同意 Proprietary 与 Open Software 两类协议；[Cubism Core 文档](https://docs.live2d.com/cubism-sdk-manual/cubism-core/)说明 Core 不在 GitHub 开源仓库提供。Front 本 PR 不下载、内置、重新分发 Core，也不代用户接受协议。

根据[官方 Expandable Applications 说明](https://www.live2d.com/en/sdk/license/expandable/)，可添加不定数量模型等应用需要专门审核和出版许可，个人/小规模通常豁免不适用于此类；完全免费的应用是否获准另有条件。**Front 的任意模型导入/工作区可能属于该类，这是基于功能的推断，发布前需要向 Live2D 确认。** 不能把“个人非商用素材授权”“SDK 本地开发许可”“Front 公开分发许可”混为一谈。当前未获得该出版许可，也未做商业授权声明。

下一阶段先取得用户已阅读接受条款的官方 Web SDK，核对具体 SDK/Core 版本及许可证，再接入按需渲染适配器，使用真实模型验证。公开安装包在明确发布资格、Core 再分发条件和模型素材许可前不得携带相关运行时/素材。
