# 本机 GPT-SoVITS 受控接入（实验性）

本入口复用 VoiceRender、Asset、版本、完整备份和共享 2 worker / 32 队列。Front 不附带、下载、安装或启动 TTS 引擎/模型，不切换服务权重，不停止用户服务。未启用时档案、手动音频、试听和导出照常使用。

## 配置顺序

1. 在独立外部环境准备自己有权使用的引擎、模型和参考声音；遵循其官方安装/许可说明。本页不代替接受协议，也不运行安装命令。
2. 核对引擎与固定 [GPT-SoVITS api_v2.py 合同](https://github.com/RVC-Boss/GPT-SoVITS/blob/04a44eb977586645f33594b72af13a035a2056c6/api_v2.py) 的兼容性。只读 OpenAPI 字段匹配不能验证实际加载权重、引擎 Git 版本、许可、音质或推理成功；没有这些只读身份接口时 Front 保持“未核验”。
3. 在 Voice Studio 登记 GPT-SoVITS 引擎，地址仅接受 `http://127.0.0.1:端口` 或 IPv6 字面回环根地址；不接受 DNS、远程代理、URL 凭据、查询、子路径或重定向。此入口不读取聊天 API Key，也不支持凭据代理。
4. 登记模型绝对路径、来源、许可和版本，关联声线，再绑定已保存的台词。路径检查只是文件存在诊断，不加载权重，也不保证外部服务正在使用该文件。
5. 仅为自己的 Front 实例设置 `FRONT_ENABLE_LOCAL_TTS=1` 后启动；默认关闭。这是高级实验入口，不要为此重启其他软件或把服务暴露到公网。
6. 选中台词，展开“本机 TTS · 显式授权与请求”。先保存草稿、人工确认小说说话人；刷新档案后重新确认本机调用、模型使用权与实际权重未核验。
7. 单独选择有权使用的参考 WAV，填写参考文字、语言和来源，确认本次使用权。声线试听样本绝不自动成为克隆参考。先预览，再明确排队；生成结果需要人工试听、采纳。

本机引擎必须与 Front 共享同一文件系统。Front 在自有 staging 创建短参考副本，校验原素材身份、Hash 和完整 PCM WAV 后才将副本路径交给本机 API；不支持猜测 Docker/WSL 路径映射。Front 的保守限制是参考 ≤30 秒/64 MiB，输出 ≤64 MiB；这些不是所有引擎的通用能力声明。不同引擎语言和参考长度要求仍需实际核验。

## 请求与失败处理

只调用 `GET /openapi.json` 和 `POST /tts`，不调用控制、重启、训练或切换权重端点。使用已保存的语言/速度、种子及明确支持的参数白名单；未知参数拒绝。有限网络超时、120 秒接收时限、分块读取与输出 PCM 校验保护 Sidecar。

项目/片段身份、合成指纹、版本、授权参考 Hash、实际参数与固定合同进入不可变请求记录。相同幂等键返回原记录，不重放；失败后重新预览产生新键再试。返回音频进入现有素材库与候选列表，不自动采纳、不覆盖原音频或小说。候选和导出清单保存实际请求参数及“模型/服务版本/音质未核验”标记。

取消只停止 Front 客户端任务。网络读取最长等待当前超时，外部推理可能继续；Front 不保证停止外部 GPU。取消、失败、关闭页面和重启保留已完成候选，重启不自动重放。正常结束/异常处理清理本次参考暂存；进程突然被杀可能留下 staging 半成品，不能据此删除原始素材。

未提交的参考文字和参数是临时表单，关闭面板不会自动创建声线资料；已提交的请求快照会持久保存。参考使用权不等于训练授权。

## 验证边界

自动测试含 HTTPX 协议服务和真实回环 HTTP 生成 WAV 服务；真实浏览器覆盖授权/预览、单句候选、试听/采纳、慢响应取消、HTTP 错误、新键重试、重启、桌面/390px 与退出清理。全部是自行生成正弦波，不是语音模型推理、真人克隆或音质验收。详见 [验收报告](audits/voice/LOCAL_TTS_ACCEPTANCE.md)。

未来真实服务验收需用户提供已部署且有权使用的引擎、模型和参考声音，另行记录实际版本、权重、语言、输出质量和性能。默认安装包不增加 PyTorch、CUDA、训练环境或权重。
