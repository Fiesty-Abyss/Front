# 模型资产与跨引擎复用

模型继续使用既有 `SDModel`、标签、提示词、生成记录与 OC 引用，没有第二套权重存储。权重只登记路径；无 GPU、无生成服务时可管理资料、导入已有生成图片并对比。

## 扫描与个人资料

模型库每页50项，目录预览和批量登记使用既有2个工作线程、32个等待任务及持久历史。预览报告每页50项，最多扫描5000文件，超限明确失败；可取消，重试不会重复登记已提交的路径。识别软件同名解压外层，仅扫描其模型资源目录，不遍历 Python 环境。跳过符号链接及越界目录。

Safetensors 只读最多16MiB头部，校验描述/形状/偏移，侧车JSON最多2MiB；不执行 pickle、不加载张量、不初始化推理。目录只是分类线索，明确的LoRA/LyCORIS头部优先。架构无证据留空，不能由扩展名推断运行兼容性。完整Hash流式4MiB读取，每块检查取消；大型单文件哈希必须使用后台任务。

新增 `sd_model_profiles` 个人覆盖表，保存收藏、星级、喜爱度、画风、场景、心得及引擎名称映射，扫描观测独立更新。既有模型名称、备注、触发词、标签与个人资料不因重新扫描覆盖。既有表不加列，启动前沿用一致性数据库快照，新表随完整备份恢复；模型外部引用默认不复制权重。

## 引擎映射

WebUI、Forge、ComfyUI名称映射仅保存在Front。出图/OC共用现有生成器，用户选择映射后使用目标名称，并在生成参数记录实际名称。不会修改生成软件搜索路径、配置、启动参数，也不创建权重副本或链接。

静态兼容检查可指出已登记架构冲突，未知架构保留待验证。用户显式确认后可查询已配置运行服务的模型目录；目录识别与实际工作流运行是不同状态。当前UI提供ComfyUI目录检查，API同时支持WebUI/Forge。未知节点、GGUF、Flux/SD3专用工作流和VAE加载仍需目标服务实际核验；内置Checkpoint工作流不承诺适配全部架构。

## 验证（2026-10-24）

- 生成文件：Checkpoint与LoRA头部、异常偏移、超限侧车、不反序列化PT、解压外层识别、后台Hash、个人资料重扫保留、架构冲突、模型资料完整备份隔离恢复。
- Mock：复用生成器的名称映射与显式服务目录检查；不是实际GPU或模型推理验证。
- 浏览器：生成样本扫描、登记、收藏/喜爱度/心得/映射保存并刷新保持，1440px与390px交互；窄屏表格内滚动、页面无横向溢出，控制台无错误。截图仅含生成文件。
- 真实只读：32个文件（17 Checkpoint、2 VAE、7 Embedding、6放大），其中20个Safetensors头部/偏移检查通过，12个其他格式仅登记。4个文件有可识别架构信息，28个未知；没有据此认定损坏或运行不兼容。未发现LoRA/LyCORIS/ControlNet，不代表用户没有其他目录。
- 32文件大小/mtime与扫描前一致，4个抽样文件完整SHA256一致。仅静态检查旧软件API路由代码存在，**未启动、连接、更新或修改旧WebUI**。模型登记在隔离私有测试数据库，0权重复制；完整路径、模型名及报告不进仓库。
- 真实32文件元数据扫描0.469秒（本机热缓存，非全量Hash）；模型个人组件独立懒加载，主入口gzip约80.80KB，上一阶段80.78KB。大规模冷盘、全部权重Hash与真实引擎验证仍待。
