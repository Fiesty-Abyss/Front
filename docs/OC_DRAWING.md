# OC绘画学习与非破坏性导出

2026-10-24。`/oc` → 绘画学习，按标签动态加载，不是完整绘画编辑器。

## 完成范围

- 学习集复用普通Collection与Asset引用，原图/参考/草稿/线稿/上色/修改/三视图/表情/服装/排线类型、日期、过程笔记。
- 练习项保存源记录身份及素材版本，原OC引用移除后练习仍保留；移除练习记录保留通用收藏集和素材。历史修改与恢复复用既有不可变版本，恢复追加新记录。
- 引用PSD/CLIP/KRA等绘画工程可记录学习过程；不宣称内部图层编辑。原文件在素材页打开，外部工具联动留待适配。
- 源图按原字节下载；后台转换PNG/JPEG/WebP。PNG编码无损不等于完整保留源文件元数据，完全保留请下载原件。JPEG/WebP转换有损。
- Pillow基础边缘线稿，白底或黑线透明底，独立派生PNG入素材库并可加入练习集。保留来源Hash/版本/操作；栅格而非矢量，不承诺人工线稿质量。不提供语义背景去除；动画首帧。
- 同一学习集并排/滑杆/叠加/差异混合，仅明确比较时读取两张原图。
- 有界任务共用2worker/32队列，持久配方/进度、取消、明确重新提交；CPU滤镜内部不能即时中断，在处理阶段边界检查取消。离开页面停止轮询，重启不自动重放。
- 源文件Hash/修改时间校验、OC/世界观/造型身份校验；3200万像素、128MiB处理上限，原件下载流式不解码。导出缓存自动清理目标7天/200份/512MiB；使用中的文件清理失败会留待后续重试，派生素材不在缓存清理范围。
- 引用与练习元数据各8MiB上限；工作流完整保存在Generation，OC引用只保留参数与工作流Hash，避免每个学习项重复嵌入大型工作流。
