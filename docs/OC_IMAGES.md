# OC图像：复用生成、手动管理与对比

2026-10-24。新增OC图像标签页，生成界面直接按需复用Generate.vue和现有sdgen引擎，不启动外部软件。

## 完成范围

- 手动图片流式入库，记录参数、关联OC/造型、共享素材内容去重；无生图服务也可比较。
- WebUI/Forge与ComfyUI复用原接口、模型/多LoRA权重、正反提示词及片段、参数、API工作流与XY网格。批次保存请求配方、模型/LoRA元数据和实际提交的Comfy图；自定义工作流只在使用相应占位符时采用表单参数，LoRA必须在节点中配置。
- 独立的Images API能力合同复用已配置Provider凭据；聊天/视觉能力不推断为生图。当前适配base64 Images API，只有prompt/size参数，其他参数拒绝。不自动下载URL返回图、不声称支持所有供应商。
- 用户明确登记能力不发请求；成功返回后记录最近成功时间。只有点击生成才发送提示词。API Key不进入批次配方、日志、错误或仓库。
- 任务保留批次/结果/配方，取消复用有界任务；页面卸载停止轮询。重试载入配方，用户再次生成才调用，可能再次计费。网络请求内的取消只能等待响应或超时，无法撤回已提交的远程计费任务。
- 生成过程中OC/世界观/造型变化时，保留素材库结果并提示，不自动污染另一归属。
- 图片并排/滑杆/透明叠加/差异混合与参数差异；仅明确比较时加载两张原图，列表使用缩略图。引用托管历史原图；索引原件改变时明确报错。

## 验证

完整197项后端测试通过；新增范围变化回归4项专题测试通过（后续全量198）。WebUI、ComfyUI、Images API使用Mock服务测试，不是真实出图。覆盖手动上传与参数比较、聊天Provider不出现、未确认合同拒绝、不支持参数拒绝、401敏感响应不泄漏、批次与工作流保存、归属变化不关联。

生产构建通过。实际浏览器生成图形文件上传、比较、滑杆与透明叠加，两个原图可加载；未配置服务按钮禁用/能力说明，390px文档380px无横向溢出。没有调用真实WebUI/Forge/ComfyUI/远程生图或读取用户原创图。

新增image_services与oc_generation_batches表，不改历史Generation字段。专用OCImages约11.51kB（gzip4.97kB），生成/比较组件按标签加载，无新增依赖；未测真实GPU耗时或十万批次。Images响应48MiB/图像3200万像素上限，后台线程仍共用2worker/32队列。

协议依据：[官方Images API](https://developers.openai.com/api/reference/resources/images)。供应商具体模型与尺寸支持由用户配置合同及实际响应确认，不靠模型名字猜测。

最终回归补充：手动PNG通过既有解析器提取内嵌SD参数（步数、种子、提示词等），再由明确录入字段覆盖，不丢失原有元数据；Images返回按实际文件格式命名。
