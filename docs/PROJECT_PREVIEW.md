# PR 2a：项目只读预览

这是创作迭代 PR 2 的预览部分，独立分支 `codex/project-preview`，叠加章节整理 #14。不是完整的世界观导入或资源版本系统。

## 使用与实际范围

- 从导航“项目预览”输入任意本机目录；可含子目录，可选择已有世界观ID作为重复报告的参考范围。不会创建世界观或导入素材。
- 复用已有导入扫描器、文件类型识别、文本解码、DOCX分析与持久后台任务；列出格式、大小、时间、图片尺寸、SHA256、基于文件/目录名称的候选分类及理由。
- 分块1MiB哈希；同目录内按内容报告重复，也查询库内相同内容。其他世界观的匹配仅报告，不合并、不关联、不覆写。世界观按稳定ID判断，不以名字判断。
- 文件列表每页50项，不携带正文或完整图片；点击才取文本片段或单张图片，图像需再次点击显示。TXT/代码最多读取64KiB、显示4000字符；DOCX XML解压量超过8MiB仅显示元数据；其他格式未接入完整预览时明确提示。
- 不执行脚本，不调用AI，不启动生成器或相机。超大图片超过1600万像素或40MiB不内嵌。复用导入器5000项上限，模型关联文件夹仍分组并提示专用扫描。
- 文件移动/修改后旧预览返回409，需重新扫描；报告读取校验目录边界和文件指纹。未扫描符号链接文件。

## 本地缓存与限制

预览报告写入当前数据目录 `project-previews/`，包括私有文件名、原路径和元数据。它们与正式世界观、素材、百科记录分开；不提供公开分享。测试全部使用仓库忽略的 `.cache` 数据目录，不提交报告或原件。不要将该目录作为公开静态站点目录发布。

指纹缓存按大小、mtime_ns、ctime_ns、设备/文件ID复用SHA256，仅用于预览性能。它不是正式导入授权或不可篡改证明；外部程序刻意保留全部元数据时可能无法识别内容变化，未来正式导入需重新校验。报告暂不自动淘汰，长期使用需有缓存管理；中断任务不自动重放，不伪称已完成报告。

当前没有原地索引模式、托管导入确认、分类编辑后入库、世界观内部标签、资源批量关联、版本差异或AI建议审核。用户选择了“先只预览，暂不正式入库”，本轮不以开发需要为由导入真实项目。原有普通批量导入仍保留，但不代表新的世界观工程导入流程已完成。

## 真实资料验证

2026-10-18，本机只读检查用户原创项目：34文件，9,424,305 bytes；13 DOCX、13 TXT、7 PNG、1 Python。全部可识别，0读取异常，未发现同内容重复文件。取得图片尺寸与文本片段；未执行Python文件，未将内容发送到AI服务，未逐张视觉验收项目图片。

首次扫描约0.130秒，第二次约0.043秒，复用34项哈希。统计含本机进程内API任务/轮询，文件系统缓存可能影响结果；不是大库吞吐、独立进程RSS或正式导入基准。哈希检查前后全部原件SHA256一致；隔离库正式世界观和素材均为0。完整私有报告只留 `.cache/project-real-verified-private.json` 与 `.cache/project-preview-real-data/`。

F盘SD归档为另一次素材适用性筛查：766张检查元数据，仅实际查看7张候选，暂确认1张非露骨头像可作本地参考；未逐张看其余759张，不能推断其他图片不可用，也没有把私人收藏适用性等同于公开展示适用性。未提交任何原图或筛查图。
