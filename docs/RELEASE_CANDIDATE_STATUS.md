当前保持内部预览版本命名，不创建v0.7正式Tag/Release。以成功Windows流水线的BUILD_MANIFEST.json、SHA256SUMS.txt及源提交为准，不能只按相同文件名认定相同构建。两种包携带冻结Python/VC运行时、共用Vue/FastAPI业务和许可清单，不包含私人数据或推理模型。更新默认禁用。
