- [x] 后端数据模型与全部资源的增删改查 API
- [x] FTS5 中文全文检索
- [x] 素材上传、缩略图、去重、日期/类型/标签/作品筛选、时间线统计
- [x] SD PNG 出图参数自动提取
- [x] 角色百科分面标签、世界观、关系网可视化
- [x] 作品与 galgame CG 归档、收藏集

## ✅ v0.2.0 · 第二轮：素材与 CG

- [x] 批量导入本地文件夹（本机路径 / 浏览器选择目录），保留原始修改日期

- [x] 差分 CG 合并显示、CG 鉴赏模式（全屏翻页、切换差分、自动播放）
- [x] ComfyUI 工作流（PNG 内 `prompt` / `workflow`）解析，下载工作流，AI 图存入提示词库
- [x] 收藏集拖拽排序、封面
- [x] 小说章节拆分、阅读模式、字数统计
- [ ] 推迟到后续：后台导入任务与进度条（大文件夹）、手动调整 CG 分组、JPEG/WebP 的 EXIF 出图参数
