1. A：六个基础对象、声库与授权/角色/OC/样本引用、历史/缺失诊断、/voice懒加载，无引擎管理。
2. B：台词项目、拆并/排序、旁白/人物/声线、句级指纹与采纳版本；生成WAV/Mock明确标记。

4. D：按确认章节建立独立朗读稿和证据、分页、有限队列、单片重生、字幕/章节合成记录。
5. F：授权参考录音、数据集/QC/切片/转写、外部训练适配、多引擎和高级音频编辑按独立PR推进；不实现完整DAW。
