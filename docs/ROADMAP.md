# 路线图

Front 按“每一轮一个 PR + 一个版本”持续开发。

## ✅ v0.1.0 · 第一轮：骨架与核心模块

- [x] 后端数据模型与全部资源的增删改查 API
- [x] FTS5 中文全文检索
- [x] 素材上传、缩略图、去重、日期/类型/标签/作品筛选、时间线统计
- [x] SD PNG 出图参数自动提取
- [x] 角色百科分面标签、世界观、关系网可视化
- [x] 作品与 galgame CG 归档、收藏集
- [x] 提示词库与“同一提示词 × 不同模型”对比
- [x] SD 模型登记（safetensors 元数据、SHA256）
- [x] 角色卡编辑器，V2 JSON / PNG 导入导出
- [x] AI 接口层：OpenAI 兼容 Provider、角色扮演对话、关系识别
- [x] 测试、CI、仓库卫士

## ✅ v0.2.0 · 第二轮：素材与 CG

- [x] 批量导入本地文件夹（本机路径 / 浏览器选择目录），保留原始修改日期
- [x] **galgame CG 识别**：按文件名规则 / 分辨率 / 差分分组，自动归档到对应作品
- [x] 差分 CG 合并显示、CG 鉴赏模式（全屏翻页、切换差分、自动播放）
- [x] ComfyUI 工作流（PNG 内 `prompt` / `workflow`）解析，下载工作流，AI 图存入提示词库
- [x] 收藏集拖拽排序、封面
- [x] 小说章节拆分、阅读模式、字数统计
- [ ] 推迟到后续：后台导入任务与进度条（大文件夹）、手动调整 CG 分组、JPEG/WebP 的 EXIF 出图参数

## ✅ v0.3.0 · 第三轮：百科增强

- [x] 角色详情页（Markdown 渲染、图集、出场作品、关系列表、所属组织 / 参与事件 / 相关地点）
- [x] 世界观下的地点 / 组织 / 事件 / 物品 / 概念条目，事件时间线
- [x] 关系网：按关系类型着色、筛选、导出 PNG / JSON、布局保存
- [x] 标签合并、别名、层级标签
- [ ] 推迟到后续：条目之间的任意关联（如“组织 A 敌对组织 B”）、地图图片上标注地点、时间线多轨并列

## ✅ v0.4.0 · 第四轮：AI 绘画工作流

- [x] 扫描 SD WebUI / ComfyUI 模型目录，预览后登记，计算 SHA256 / AutoV1 / AutoV2 / AutoV3（后台任务）
- [x] 按模型哈希匹配 Civitai 元数据（可选、需联网，可完全关闭）；读取本地 `.civitai.info`
- [x] 提示词片段库（质量 / 画风 / 角色 / 服装 / 动作 / 构图 / 背景 / 光影 / 负面），组合器调权重与顺序
- [x] 接入 SD WebUI / ComfyUI API 直接出图，自动入库、自动记录对比与批次
- [x] 对比视图：参数差异高亮、参数差异表、提示词增删、XY 网格
- [x] 修正：上级标签的使用次数包含子标签
- [ ] 推迟到后续：img2img / 局部重绘 / ControlNet、出图队列持久化（目前任务保存在内存中）、Civitai 以外的站点、模型重复文件检测

## ✅ v0.5.0 · 第五轮：AI 角色与世界观智能

- [x] 对话流式输出、停止、重新生成、编辑消息、分支切换
- [x] 世界书 / Lorebook（character_book）编辑、关键词触发、命中测试、导入导出
- [x] 多 Provider 配置界面（设置页管理服务、测试连接、按用途选择）
- [x] AI 从小说抽取角色条目与关系，与已有角色对照后写入
- [x] 向量检索（语义 / 混合检索、找相似；本地 n-gram 或嵌入模型）
- [x] 图片自动打标签（WebUI WD14 Tagger 扩展或视觉模型，可选）
- [ ] 推迟到后续：内置 WD14 ONNX 本地推理（不依赖 WebUI）、精确 token 计数（目前按字数估算）、长文本分块向量化、抽取标签 / 世界观条目、世界书的概率 / 分组 / 插入深度等高级字段（导入时原样保留但不生效）、在真实大模型上系统调优提示词
