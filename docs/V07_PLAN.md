# Front v0.7 开发与验收计划

依据：2026-10-18 用户任务书。保持 Vue 3 + FastAPI + SQLite；Web 与 Tauri 2 桌面共用后端，不重写已可用的功能。普通用户的正式包不依赖安装 Python、Node、Rust、IDE 或执行命令。

首轮实际差距见 [审计报告](audits/v0.7/README.md)。开发工具、依赖、隔离数据和缓存只放在当前工作目录下；生产软件的数据位置按下面的正式数据策略实现。

## 不可取消的约束

- 升级不能重置数据库；迁移必须有可追踪版本、可重复测试、兼容检查和恢复点。未验证的历史库不得自动全量迁移。
- 个人数据库、素材、API Key 与程序文件分离；安装版使用系统用户数据目录。便携版允许独立数据目录，但检测只读/权限不足，提供可操作的替代位置，不静默丢数据。
- 支持独立自定义素材目录；同文件属于多个集合只增加引用。大模型优先登记原路径、Hash 和元数据，不强制复制。
- 未确认不能覆盖现有笔记/角色卡；默认不删除原始素材。受管理副本删除与数据库事务要保持可恢复；文件清理失败允许保留待回收文件，不能反过来破坏库。
- 下载文件、外部程序、媒体预览都视为不可信输入；限制路径、大小、解压预算和外部链接。AI 密钥不能出现在日志、截图或 Git 中。
- 继续雾紫深色品牌，提供浅色与明确的加载/失败/空态；视觉为效率服务，遵循减少动态效果，不把重绘和 WebGL 放在未使用的页面中。
- Krita / ComfyUI / WebUI / Ollama / SillyTavern / Steam 等分别通过独立适配器接入；不配置就不初始化或轮询，不影响核心。

## 更新与发布

- GitHub Releases 才是正式来源；正式 Tag 才触发正式包。提交、Push、PR 不弹用户升级提示。
- 启动时检查稳定版，设置页手动检查；新版说明、稍后提醒、下载/安装进度、失败反馈与稳定/测试通道。
- 使用 Tauri 官方 Updater；更新包校验签名。签名私钥不在 Git，公开校验材料与打包清单可入仓库。
- 便携版如果不能安全原位替换，就下载新版并沿用外部数据目录；不得强行覆盖运行中的文件。
- Windows x64 流水线：测试 → 前端构建 → 后端 onedir → Tauri 安装包 → 便携包 → 哈希/签名校验 → 附件/更新清单 → 正式发布。失败时不发布不完整版本。
- macOS/Linux 等有可验证环境后再加；本轮不能用未经测试的平台产物占位。

## 每轮接续记录

1. 只改当前阶段需要的代码，复用已有模块。
2. 自动化测试、前端构建、实际 UI 与风险相关验证，记录真实/生成/Mock 的区别。
3. 更新变更说明、[进度](V07_PROGRESS.md)、性能前后值和未解决问题。
4. Commit → 推送功能分支 → PR → 汇报验证和风险。不得强制推送 main。
5. PR 合并和正式 Release 分开；签名、历史数据与安装测试未过，不声称 v0.7 已交付。

## 正式验收清单

- [ ] Windows x64 安装版可下载、安装和启动，干净环境不需要开发工具。
- [ ] Windows x64 便携版可解压运行，更新保留外部数据，权限失败有明确处理。
- [ ] Web 开发和自托管模式继续可用，共享同一业务逻辑。
- [ ] 大量素材与笔记可实际管理，列表全部可达，筛选/搜索/批量操作可用。
- [ ] 模型、提示词、反向提示词、LoRA 参数、手动图片对比、风格评价可在无 GPU 环境操作。
- [ ] 统一收藏、星级、喜爱度、标签、备注与多集合引用可用。
- [ ] 合法真实样本、生成样本、损坏文件、大文件、丢失路径与关联文件均有证据。
- [ ] 迁移可追踪、备份可实际恢复、崩溃后 DB 和素材一致；旧用户库兼容性有测试。
- [ ] 新版检测、通道、签名拒绝、失败恢复、安装版与便携版更新均实测。
- [ ] Tag 流水线可稳定产出完整 Release 附件；任何失败不发布坏包。
