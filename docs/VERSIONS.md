# PR B：非破坏性版本与对比

## 行为与兼容

沿用素材/百科/笔记/关系及章节目录。素材详情、世界观设定、项目档案中的人物/条目/笔记/作品/关系可以明确启用版本记录。启用前不迁移历史数据；启用后ORM编辑在同一SQLite事务追加快照，目录编辑也会记录。历史列表分页且不读取正文快照。

不可变JSON快照按SHA256复用，相同内容不重复存储；恢复追加新记录、复用旧快照。文本按段落/行显示增删修改，结构化字段递归比较。正文和目录同时保留；兼容正文的旧目录恢复为新的ChapterRevision。图片提供并排、滑杆、透明叠加和原始分辨率滚动。不同尺寸不自动配准，绘画工程只保存文件版本和元数据，不伪称图层或网格编辑。

托管媒体复用原内容地址，不再次复制大文件；版本引用的文件受保留标记保护，删除素材也不自动清除历史媒体。原地索引只快照文本/元数据，不悄悄复制原件，也不宣称保存旧图片字节。“固定当前原文件”需界面确认，流式校验SHA后保存托管副本。上传新版先进入现有素材库，再明确采用；保持原档案ID、世界观和来源，新文件内容另存，原件不改写。

新增表前沿用PR A数据库在线备份，不重建历史表。历史与当前对象通过独立generation隔离，SQLite ID复用不会暴露旧历史。恢复检查最新版本（BEGIN IMMEDIATE锁内）、世界观归属、关联创建时间和标签身份；失效关联拒绝自动恢复。不提供删除历史API。

## 验证与性能

- 180项后端测试通过，生产构建通过。新增测试覆盖正文/字段差异、恢复追加、回滚、重复快照、媒体共享/保留、索引明确固定、目录恢复、主对象及关联ID复用。
- 浏览器生成文本实际启用→编辑→比较→确认恢复，看到新增历史及恢复原文。生成640×400 PNG实际采用新版→并排/滑杆/透明叠加，验证尺寸及裁切/透明度；旧媒体可读取。原生确认曾阻塞自动验收，改为页内确认并重新验证。截图仅生成样本。
- 本机HTTP、56,000字符生成文本、各10次备注保存：未启用历史中位9.88ms，启用后11.28ms；11条历史响应1,792bytes。不是长篇/高并发/RSS基准。版本面板独立chunk约8KiB（gzip约4KiB），无新依赖、AI或GPU常驻服务。
- 真实项目沿用PR A归档验证；未覆盖真实文件、未固定真实原件、未上传正文到AI。版本验收为生成文件，未冒充真实绘画工程编辑。

## 限制与接续

快照为内容去重的完整JSON，不是逐段增量；同一长篇实质变化仍占全文空间，超长字段比较仅显示片段，暂不支持单字段/手动三方合并。启用记录前的变化无法追溯。未固定的索引旧图不能保证恢复，界面明确显示。

历史媒体暂无垃圾回收/保留期限界面，磁盘空间需后续可审核清理。SQLite快照仅数据库，不含外部源和媒体；完整备份恢复继续是v0.7必交付项。ORM正常写入受记录，直接SQL标签批量合并/级联删除不生成每个对象的变更版本；快照保留，恢复时失效关联报错。删除的资料暂无自动重建入口。AI摘要/冲突分析、平行分支及大库RSS测量仍待。
