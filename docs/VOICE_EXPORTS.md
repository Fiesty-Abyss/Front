# 配音片段导出

本机TTS候选的导出来源清单已补充实际请求参数、固定合同、参考版本和未核验模型/服务版本/音质标记；不回显本机API地址或模型绝对路径。导出本身不执行推理；字幕仍按片段时长排序，不是逐字对齐。新增生成协议候选→采纳→ZIP断言，真实TTS质量仍待验收。


## 已采纳配音片段的WAV与字幕导出

复用VoiceProject/Segment/Render、Asset、版本、完整备份和2worker+32有限队列。当前页有效片段先预览/确认、最多100条/20万字符，按工程排序；必须各自已采纳且指纹、素材身份/世界观与实际Hash一致，小说候选须先人工确认。新增单独voice_exports状态/不可变请求快照表，不改历史字段，升级前使用既有在线快照；任务失败/取消/重启不重放推理。

后台只接受完整且相同声道/位深/采样率的PCM WAV，单轨≤64MiB、总PCM≤128MiB，64KiB分块；ZIP包含audio.wav、SRT、VTT与来源/参数/版本/帧区间清单，字幕按片段音频时长顺序计时，不是语音强制对齐。Mock标记会保留，未执行TTS或自动转码。长篇需用户分批选择；不把当前页导出称为整章/整本自动合成。

任务具有持久幂等键、取消、明确新请求重试及中断记录，导出成品进入共享素材与版本保留，不改原音频/小说。失败不提供可下载成品；磁盘/提交故障可能留下未关联的内容寻址媒体，沿用现有保守保留策略，不能擅删用户文件。自动测试仅用生成PCM/隔离DB、包含格式/损坏/顺序/过期完成/取消/恢复；适用CI及最新通过head以本PR/Actions为准。真实TTS、MP3转码、全章自动选择/混音、GUI窄屏/播放和真实性能仍待验收。

使用：/voice → 台词工程 → 先为当前页每条台词关联并采纳音频 → 展开导出面板 → 预览 → 确认排队 → 刷新记录 → 素材档案下载ZIP。翻页后分别导出；不自动轮询、不默认选择整本。无GPU或TTS引擎仍可用手动音频。
