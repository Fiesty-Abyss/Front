# 参考音频档案与本机技术检查

入口：AI Voice Studio → 参考音频。直接选素材库音频，不复制原件；标题、标签、评分、收藏沿用 Asset，试听使用现有 AudioPlayer。界面按需加载，无引擎仍可管理。

## 来源与用途

每份音频可保存一份当前参考档案，包括试听/零样本/训练资料类型、可选声线 ID+UID、参考语言、人工文本、来源、许可、用途声明及备注。未获授权可保存待审核资料；勾选零样本/训练范围时，必须同时填写声音使用权、来源、许可和声明依据。记录是用户声明，不是 Front 核验许可或身份，也不会启动推理/训练。

参考专属列表只返回摘要，通用素材列表也不携带参考长文本/QC命名空间；打开单项详情、版本或备份仍能读取完整资料，不从列表响应推断使用权。

声线关联检查稳定 UID 与世界观/作品归属，ID复用或归属变化不能自动重绑；需先明确解除关联再审核。独立参考无需角色或世界观。同一音频的多套并行参考预设、训练数据集和切片仍待后续。

已登记的用途限制在受控本机TTS的排队、调用前及结果入库前检查。试听/训练范围不能代替零样本声明，撤回声明后新请求被拒绝；已发出的外部请求无法撤回，结果入库前的复核会阻止 Front 采用不再满足声明的返回值。既有成品保留，不自动删除。尚未登记参考档案的旧流程仍须逐次明确声明使用权；保存档案不替代本机调用、模型权利和参考授权确认。

## 原件、版本和备份

档案保存于既有 `Asset.meta.voice_reference`，技术报告位于 `voice_reference_qc`；命名空间 schema=1。无第二套文件库、队列或数据库表/字段。更新只合并专属字段，保留素材的其他元数据、收藏/评分、笔记及文件引用；要求 id+创建身份+Hash+当前素材版本。较新或未知命名空间拒绝覆盖。

复用 Asset 的不可变版本和完整备份；恢复追加版本。界面中的历史属于整个素材，包括标签、备注和文件引用，不是仅回退参考字段。外部原地索引的历史不自动保存旧原始字节；技术报告只对应当次校验的音频Hash，后续移动/修改需重新检查。

刷新保留未保存输入与旧并发版本，陈旧保存返回409；明确重载才放弃草稿。Voice 的参考页及原档案页增加离开/关闭草稿保护。后台分析期间其他编辑发生时，报告不覆盖新资料。

## 技术检查

明确同意后才在共享有限后台队列执行，不发送到任何引擎/API。每次最多64MiB完整PCM WAV，复制到 Front 自有暂存并校验实际Hash，再分块分析，原件只读。报告与版本持久保存，正常失败/取消清理暂存；突然终止可能留下自有半成品，不能据此删除原文件。

报告包含时长、采样率、声道、位深；PCM16额外计算全部采样的峰值/RMS、近零采样比例、近满幅采样比例与整轨零静音。近满幅（幅值≥32760）是削波风险提示，不证明已经失真；不是LUFS、噪声/SNR分析、语义质量、说话人识别、转写或授权认证。其他PCM位深只报格式，不给出未测的音量结论；不自动转码、降噪、切片或改原音频。

超过当前 Front 单次TTS参考30秒限制只提示，不能视为所有引擎的通用时长要求。缺失/Hash变化/截断/不支持格式/权限问题显示稳定错误，已完成报告保留历史。取消只终止本次本机分析，不停其他服务。
