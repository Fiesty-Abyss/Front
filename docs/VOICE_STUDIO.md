# AI Voice Studio · foundation

## 可用边界

`/voice` 动态导入，登记引擎、外部模型、独立/角色/OC声线。支持来源/许可、语言/引擎声线标识、试听素材引用、全局标签、收藏、0–5星、0–100喜爱度、备注。列表分页30项、API上限100，搜索按名称；编辑显式保存，不自动覆盖。

三个档案使用不可变uid和现有EntityVersion，创建即启用历史；PUT要求uid+expected_version，陈旧编辑409。历史恢复追加版本，角色/世界观/作品/试听素材身份变化拒绝静默恢复。解除绑定后才能明确重新关联改变归属的角色。同名角色不做合并。

试听选择现有Asset，只接受音频及当前身份/Hash；复用AudioPlayer，点击才创建，不自动播放。失效引用显示诊断，不冒用SQLite复用的整数ID。无推理服务仍可管理与试听已有文件。

模型只登记原始路径，不复制、不加载、无Hash重任务。用户点击诊断仅对所登记本地绝对路径stat；拒绝URL、UNC及相对路径；不会递归扫描。`file_present`只代表存在，兼容性永远显示unknown/runtime_verified=false。引擎仅登记配置，能力未验证且synthesize=false；聊天API不能据此成为TTS。凭据只引用现有AIProviderConfig ID，不返回或写入声线历史中的密钥。服务地址禁止嵌入账号密码、查询参数和片段。本阶段无网络请求。

## 数据兼容及复用

同一SQLite增加VoiceProvider/VoiceModel/VoiceProfile/VoiceProject/VoiceSegment/VoiceRender和声线标签关联表；后三表只是工程阶段的结构预留，没有配音/生成API，不声称完成台词编辑。没有新增底层文件库、音频播放器、队列或推理依赖。

复用启动前一致性快照、create_all加表；不改旧资料表字段，不重置数据库。版本、音频Asset与关联在现有完整备份中保存，恢复继续写隔离目录。外部模型路径仅随数据库登记，不把模型权重复制入包。

## 验证与性能范围

新增test_voice_studio使用自动生成WAV、伪模型字节和隔离SQLite，覆盖档案、参数校验、凭据不泄漏、分页、范围变更、ID复用、并发编辑、追加恢复、备份隔离恢复及旧库备份。实际结果见对应PR的Actions，不把测试名称视为已通过。

列表不会读取许可/长备注或原始音频，不访问模型路径；单页上限100。公开样本测试断言5条长备注场景分页响应小于6KB。未进行本机GUI/窄屏交互、首屏/内存/GPU或真实TTS测量；界面构建不替代交互验收。

## 下一阶段

台词工程/拆分合并/单片失效与候选采纳 → 统一TTS协议及明确标记的Mock → 有声小说章节工程。当前没有真实合成、克隆、训练、音质结论、字幕/成片导出或波形时间轴。未来适配器必须核对官方版本和请求格式，单独处理请求安全/幂等/取消及授权参考音频。不启动用户已有服务，不自动接受许可或下载权重。
