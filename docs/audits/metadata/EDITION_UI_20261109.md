# 图书版次核对界面 · 2026-11-09

独立基于 main `69cb89bf21468c8f501b74f3d4297be9867e991c`，复用 #69 ISBN/OL…M/OL…W、metadata/jobs、原字段来源和人工应用。没有新表、迁移、Provider、下载器或推理依赖。

## 实际缺口与改动

- 原搜索输入只写“公开书名”，没有说明现已支持 ISBN；现标明 ISBN-10/13 与后端联网前校验，增加已有 API 支持的可选年份，用于匹配核对。非图书检索不携带隐藏的作者/年份条件。
- 原候选只显示书名与来源ID；现区分具体版次与作品级条目。必须同时满足来源、OL…M 身份与 edition 标志才能称具体版次，不能仅凭题目或匹配分数判断同一译本。
- 原无目标档案时看不到详细字段；现始终可核对来源作者、ISBN、版次、出版商、日期原文、语言代码和所属作品ID，缺失明确写“来源未提供”。不补造作者或译者，不自动翻译语言代码。
- 应用比较与历史来源使用中文字段名，继续逐字段勾选/明确替换/刷新许可，保留原并发指纹与版本恢复。显示详情不写目标、不下载封面或正文、不请求图床。
- 新摘要仅文本与语义 dl，窄屏折行；不增加动画、大型 UI 库、常驻任务或原图解码。

## 验证边界

Node 使用生成来源记录、真正 Vue SSR 验证原始身份/字段、未知值、未选择目标的展示和HTML转义，测试摘要没有 img/src 或外部封面地址。搜索体测试年份上限、空值和跨种类条件隔离；后端 #69 ISBN校验/错误版次/人工覆盖/缓存等现有测试继续执行。

首次测试夹具试图 resolve 非导出的 Vue index.mjs 子路径，改用公开 import.meta.resolve('vue')；不增加依赖或修改产品模块。另一断言原本精确匹配开发模式注释，改为验证没有可见摘要内容，不绑定 Vue 内部注释文字。
