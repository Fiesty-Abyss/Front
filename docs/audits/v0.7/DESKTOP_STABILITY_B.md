# 桌面稳定性 B：启动、目录与隔离升级

基线main `2eccdb5`（PR #29正常合并，backend/frontend/windows-x64均success），独立分支`codex/desktop-startup-regression-b`。不共享正式Web或真实资料目录。

## 改动

启动前在用户数据根、logs、media和thumbs中执行可创建、写入、flush/fsync与删除的临时探测；失败返回静态`data_directory_unwritable`，外壳给出权限/磁盘/便携目录提示，不打印私有路径。损坏SQLite与不兼容结构均返回`database_incompatible_or_damaged`，拒绝继续迁移。没有修改数据库结构。

`desktop/regression_sidecar.py`拒绝任何已存在的目标根，使用生成资料与中文/空格/&路径。启动握手有45秒上限，失败只清理脚本自己创建的进程；测试不会接受用户真实库作为现成根。
