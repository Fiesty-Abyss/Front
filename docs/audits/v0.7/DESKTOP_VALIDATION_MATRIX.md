## 证据分级

| 标记 | 含义 |
| --- | --- |
| 真实本机（历史） | 用户日常Windows电脑上运行过真实冻结包或原生窗口；存在开发工具/已有WebView2，不是干净系统 |
| Windows CI（历史） | Windows runner执行真实构建或冻结包HTTP操作；runner预装软件不能替代干净VM |
| 生成样本/自动测试（历史） | 隔离生成文件、SQLite和源代码测试，明确其验证层次 |
| 模拟/部分 | 环境、权限或更新源以隔离测试方式模拟，仅覆盖标明部分 |
| 未验证 | 没有对应证据，不填通过、不用Mock补成真实验收 |

真正干净Windows环境当前尚未确认可用。若无法取得，应保持该列未覆盖，继续进行其余不依赖项，不要求用户夜间操作。

## 性能与长期稳定性衔接

阶段A负责新测量，阶段B只引用可核对的报告。历史9进程RSS求和814.7MiB包含重复共享页，PrivateBytes634.7MiB不是私有工作集；GPU专用显存未测，不能把外壳24.1MiB称为软件总占用。历史1.79秒是热回环服务就绪，不是冷启动或首屏交互。

本轮待填：真实进程树/运行时版本、冷/热定义、首屏可交互时间、WebView/后端/外壳分项，工作集/私有提交/共享/GPU口径，连续路由切换后回收，后台轮询/计时器/图片解码，Three/Live2D/audio实例清理，以及长时和大量素材后的变化。没有新报告前全部保持未验证。
