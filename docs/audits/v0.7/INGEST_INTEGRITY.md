# 托管重复素材校验


## 托管重复素材完整性保护

源码证据：ingest_stream原先只凭数据库SHA和file_path直接返回旧记录，磁盘文件已丢失或同长度损坏时仍会被重复导入/原地索引采用；无记录但内容寻址目标已占用时也跳过校验。现在只读分块校验实际大小、SHA256及读取前后文件身份，错误返回409与无路径错误码，不覆盖、补写或删除旧文件；仅清理本次staging。保留原始素材元数据、手动备注和历史。语音任务沿用明确的存储错误码。

重复项额外读取至多新输入大小+1字节，单次块≤1MiB；大小不符即拒绝，不读无限损坏大文件。正常新文件没有第二次完整Hash。无数据库迁移、新依赖或常驻后台任务。生成样本覆盖正常/空文件、同长篡改、增大/缺失/目录、不可读/越界路径、孤立内容路径、原地索引及读中变化。当前CI待本分支验证，真实磁盘大文件性能、跨进程校验后篡改和用户库修复均未宣称完成。

验证方法：仅Actions的生成二进制和隔离临时目录；不操作用户库。安全拒绝不代表备份已损文件可自动恢复；用户应在独立目录核验备份后再决定恢复。
