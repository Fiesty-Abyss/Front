# RC D：可见启动阶段与有界生命周期

2026-11-07。基线为已合并PR #38；不增加推理服务，不改变用户数据目录或升级备份门槛。

原生壳先创建一个本地静态窗口，再在工作线程启动本实例Sidecar。备份、校验、隔离恢复、迁移和服务启动使用固定阶段提示；有文件计数时显示进度，不把路径、文件名、API Key或原始异常传入页面。复用同一WebView，进入Vue后不保留隐藏渲染窗口、进度轮询或动画循环。早到事件由当前状态重绘，避免页面尚未加载时丢失错误。

默认Sidecar握手保持兼容；新壳显式传入`--startup-events`。单行4096字节、队列8行；校验已启动子进程PID、端口及令牌形式。普通启动120秒，实际备份/恢复/迁移最多总计1800秒，不因心跳无限延期。关闭窗口使初始化取消；失败停止已分配Job Object的本实例子进程。原备份与资料保留，不自动重置数据库。

窗口导航只允许本地启动页及其后确定的本实例loopback origin；Updater IPC只授权主窗口的该HTTP origin。正式公钥仍未配置。无新增依赖。

每次启动最多三次写入`logs/native-startup.json`，仅数值：PID、窗口创建、服务ready、主文档load完成、初始物理尺寸和缩放倍数。**窗口创建不是实际首帧显示；文档load不是TTI**。禁止把这些数字作为真实可交互验收。
