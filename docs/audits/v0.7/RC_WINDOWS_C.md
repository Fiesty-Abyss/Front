# RC C：真实Windows ACL与启动预检

2026-11-07，Windows11家庭中文版22631，日常开发主机，**不是干净VM**。本阶段修复可复现的权限拒绝卡顿，未宣称完成安装升级矩阵。

## 证据与实现

独立生成目录对当前账户施加真实Write Deny ACE，.NET确认写入被拒绝。旧TemporaryFile因Windows的os.access仍返回可写，将PermissionError当作文件名冲突，重试最多TMP_MAX次。源程序观察超过60秒仍未返回，停止已核对的子进程，finally恢复ACL，哨兵文件仍在且恢复后可写。

改为随机名称单次`xb`独占创建、写入/fsync/删除。只删除本次成功创建的探测文件；权限、碰撞、设备错误返回稳定data_directory_unwritable，不打开/迁移DB。碰撞和fsync失败注入覆盖原件保留、失败临时文件清理和只尝试一次。

新PowerShell工具只接受本checkout全新.cache目录，拒绝旧输出及祖先junction/symlink。保存原SDDL到隔离目录，finally恢复ACL，复核写入及哨兵SHA256。不输出账户SID。子进程15秒截止，即使回归也不会无限等待。

- 真实源进程ACL拒绝约0.357秒。
- 本机PyInstaller6.22.3/Python3.13 onedir，最小System32 PATH：真实冻结拒绝约0.517秒，没有front.db创建；ACL恢复、生成哨兵Hash不变。
- 同一冻结Sidecar首次ready1.090秒、重启0.992秒；多实例、记录/媒体保留和令牌轮换、旧结构完整备份+隔离恢复、损坏/未来库不改写、无效目录错误通过。是服务ready，非窗口/TTI。
- 源4项启动专项通过；集成完整测试和Windows3.12 CI另记录。流水线新增冻结后的真实Deny ACE门槛，失败不上传测试附件。
- PyInstaller缓存和TEMP/TMP/TMPDIR固定项目.cache。首次本机构建曾使用默认用户缓存，检查时已完成，随后按项目缓存重建；未对默认缓存做额外清理。包内README更正为“更新底座已实现但默认禁用”。
