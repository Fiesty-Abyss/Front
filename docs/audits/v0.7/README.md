# Front v0.7 第一阶段审计

日期：2026-10-18。基础版本：v0.6.4，提交 `3fcf88b`。本轮为审计与定向修复，不是 v0.7 正式发布。

**结论：尚不能作为 v0.7 桌面正式版交付。** Web 核心已有相当多的真实业务实现，应继续复用；桌面交付、整库恢复、升级保护、统一偏好与大型素材库操作尚有明确缺口。

## 证据与验证范围

- Windows，Python 3.13.9，SQLite 3.50.4；Vue 3 / Vite 生产构建，由 FastAPI 托管。无 GPU、无真实 AI 服务参与。
- 完整列举 **227 个 API 操作**：[API 清单](api-inventory.csv)。这是接口库存，不代表逐个接口均经过完整验收。CRUD、错误边界和各模块核心路径由现有及新增的自动化测试验证。
- **26 个前端路由**：1440×1000 桌面和 390×844 窄屏检查；[页面矩阵](pages.md)、[机器记录](browser-results.json)、63 张页面及预览截图。矩阵标注的是首屏和加载检查，不是所有按钮、所有编辑分支均通过。
- 自动化：**143 passed**，0 skipped，约 32.26 s；1 条第三方 Starlette TestClient 弃用警告。前端生产构建通过，约 6.10 s。两者按顺序执行，避免 Vite 清理 dist 时影响 API 静态目录测试。
- 生成文件：PNG / JPG / WebP / GIF、TXT / Markdown、DOCX、PDF、WAV、GLB、VRM、OBJ、PMX 包、Live2D 结构包、SVG、损坏 GLB。视频由已有测试通过 FFmpeg 生成并验证；本机有 FFmpeg，没有跳过该项。
- 浏览器实际操作：笔记编辑、Ctrl+S 后重载核验、Ctrl+K 搜索、搜索命中打开对应素材、异常搜索模式回退、侧栏折叠、深浅主题、静音音频播放；PDF 页图实际解码宽度 1100 px。
- 所有数据在 `.cache/audit/` 内生成。人物、游戏、图片、模型均为示例；游戏、SD 出图与 AI 对话的种子数据使用本机 ASGI Mock。未访问真实游戏平台或真实模型服务，未使用个人数据库。
- **尚未验证**：真实专业 PSD / PSB / CLIP / KRA 工程、复杂生产 FBX / 完整 VRM 人形动画、真实 Cubism 模型、真实大模型和 GPU、GB 级资源、万人物关系网、进程崩溃 / 断电、全部历史数据库快照、安装与升级。这些是后续验收门槛，不能拿生成样本的成功替代。

复现命令（开发环境）：

```powershell
# frontend 构建完成后再运行后端测试，不与测试并发修改 dist
cd frontend
npm ci --ignore-scripts --cache ..\.cache\npm
npm run build
cd ..\backend
..\.venv\Scripts\python.exe -m pytest -q --basetemp=..\.cache\audit-tests
cd ..
.\.venv\Scripts\python.exe backend\tools\audit_baseline.py --run unique-run-name
```

基线工具拒绝覆盖已有 run，输出独立生成数据库、API 库存、文件识别结果和测量 JSON；不是个人数据备份工具。浏览器验证需使用生成的数据目录启动本机服务，禁止对个人库运行种子数据写入。

## 本轮已修复

1. **Blocker：SPA 静态回退目录越界。** 编码路径可访问构建目录外的文件。现在解析真实路径并限制在 dist 内，拒绝跨平台反斜杠路径；新增测试。
2. **High：不存在的 API 返回 HTTP 200 HTML。** `/api` 前缀未命中时现在返回 JSON 404，避免把接口错误伪装成成功。
3. **Blocker：删除事务回滚后文件丢失。** 原模型 after_delete 和文件分离接口在数据库提交前 unlink。生成文件复现：记录恢复=true、文件保留=false。改为事务提交后清理，覆盖普通回滚、savepoint、会话关闭/复用和目录外路径；复测文件保留=true。崩溃发生在“提交后、清理前”时可能留下孤立文件，后续需安全回收，但不会因为数据库回滚丢掉文件。文件系统与 SQLite 仍不是跨系统原子事务，不能声称断电安全已完成。
4. **Medium：素材搜索结果只打开列表。** 改用现有 `?open=<id>` 详情入口，浏览器实际命中正确素材。
5. **Medium：异常搜索 mode 导致渲染异常。** 非法参数回退到关键词模式，浏览器复查有 20 条正常结果。

| 级别 | 问题与证据 | 影响 / 下一步 |

| High | 未知 Host 请求 `/api/stats` 返回 200；无桌面实例 token/来源保护 | 默认仅监听 127.0.0.1 仍需防本机其他来源与 DNS rebinding；桌面按实例授权，Web 显式允许的主机与来源 |
| High | 上传先 `await file.read()` 再检查大小；导入 `read_bytes()`，部分解析整文件读入 | 大文件内存峰值和阻塞；统一有界流式入库、磁盘临时文件和后台解析 |

| Medium | 非法 year/date/world_id 筛选实测 HTTP 500 | 查询参数应有明确的 422 校验；避免把错误输入变成服务端异常 |
| Medium | 模型/片段/世界书搜索只跳列表，部分列表 500 上限 | 其他实体的精确命中和分页要继续补齐，本轮只修复已复用的素材详情入口 |
| Medium | 窄屏自动折叠导航隐藏文字，而 aria-label/title 未同步补齐；弹窗没有完整焦点约束 | 图标导航、键盘和屏幕阅读器体验不足；补语义、焦点返回和表单标签 |
| Medium | 部分压缩包/关联模型读取仍需统一总大小、外链和路径策略 | 未完成恶意文件、外部纹理、丢失关联文件的系统回归 |
| Low | 图谱 wheelSensitivity 和 THREE.Clock 有第三方警告 | 不等于功能失效；实际浏览器日志保存在机器记录中，后续按测量处理 |

## 性能基线

原始值和方法见 [baseline.json](baseline.json)。本轮没有宣称完成性能优化。

- 2053 个素材记录，其中 2000 个是额外生成的元数据记录（1500 reference + 500 带正文 novel），**不是 2000 张真实大图**。浏览器测试另外创建 1 页生成笔记，故页面数据与 API 基线的 notes 计数不同。
- ASGI TestClient 进程内串行测量，每接口 15 次；中位数 / nearest-rank P95。包含客户端序列化和应用调用，不含 TCP、真实浏览器、磁盘冷缓存或远程服务延迟。
- 素材 `limit=200`：响应 **1,309,993 bytes**。正文仍包含在一些列表项中，是减负的直接目标；ASGI 中位约 10 ms，不能据此说大库浏览流畅。
- 第二页 `offset=200` 响应约 1.71 MB；中文关键词搜索响应约 3.4 KB，中位约 2 ms。现有 API 有 offset，UI 尚未消费。
- 34 MiB 未解析测试文件上传成功；tracemalloc 峰值 **107,010,816 bytes**（约 102.1 MiB）。这是同进程 ASGI 客户端与服务器的 Python 分配峰值，**不是独立后端 RSS**。
- 单独启动的 Uvicorn 进程：预览前工作集 107,728,896 bytes，PDF/媒体预览后 131,198,976 bytes；单次 Windows Get-Process 快照，不含浏览器，也不是稳定性/泄漏曲线。
- 空库 `create_app()` 约 57 ms，不是桌面端冷启动到可交互时间。打包后必须另外测量启动到窗口与 API ready 的全过程。
- 3D 查看器原始 chunk 约 892 KB、笔记编辑器约 700 KB，主入口约 211 KB；均有拆包。构建包尺寸不是实际首屏加载量；后续记录路由首次加载资源、LCP/INP/CLS 与空闲 CPU，不能用构建输出替代这些指标。

## 数据库与发布判断

生成数据库：46 张表（含关联表与 FTS 辅助表），47 个索引（含 SQLite 自动索引）；`integrity_check=ok`、`foreign_key_check=[]`。这只能说明该样本的结构一致，不证明媒体与 DB 事务一致，也不证明全部历史数据兼容。

新增的历史迁移测试使用**合成的 v0.5 前线性对话结构**，验证消息内容保留、父链和 head 正确、第二次迁移无操作。它不能代替真实各版本数据库快照；迁移账本/备份/可回退兼容检查尚未实现。

当前机器未发现 Cargo/Rust/MSVC 命令；这不是要求普通用户安装工具的理由。桌面端应在 Windows CI 产出 Tauri 2 + Python Sidecar 安装版与便携版，并在没有开发工具的环境验证。仓库目前只有测试/构建 CI，没有签名 Release 构建流水线。

接续顺序与发布门槛见 [v0.7 开发计划](../../V07_PLAN.md) 和 [进度记录](../../V07_PROGRESS.md)。本轮完成后仍然是 **Do not ship yet（针对 v0.7 正式桌面版）**。
