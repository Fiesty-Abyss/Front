## 已复现与源码确认的问题

| 项目 | 基线证据与触发条件 | 用户影响 | 计划处理与验收条件 |
| --- | --- | --- | --- |
| 收藏集窄屏编辑区不可见 | `Collections.vue` 外层固定 `300px 1fr`；390 px 检查中左栏占据可用宽度，右侧表单完整落到视口外 | 无法在正常视野内编辑名称、说明或保存 | 小屏改为单列，子项允许收缩，封面与表单可重排；390 px 实际创建、编辑、保存后重新打开验证，避免依赖横向拖动 |
| 导航失去可访问名称 | `style.css` 在 900 px 以下隐藏 `.nav a .lbl`；`App.vue` 仅在 `collapsed` 为真时设置链接 `title`。CSS 自动收窄但状态仍为假时，隐藏文字无法继续作为可访问名称 | 图标导航对辅助技术及不熟悉图标的用户不清楚 | 链接始终提供稳定名称，与视觉折叠状态解耦；复查两种 `collapsed` 状态下的可访问性树及键盘导航 |
| 空音轨区间反向 | `audio.txt` 为 `0轨 · 当前1–0`；模板直接使用 `offset+1` 作为起点 | 空状态显示自相矛盾 | 空列表显示 0 或无区间；覆盖 0、1、50、51 项及搜索归零情形 |
| 阅读目录缺少键盘语义 | `Reader.vue` 目录使用没有 `href` 的 `<a @click>` | 不能依赖原生链接焦点和激活行为切换章节 | 采用可聚焦、可键盘激活的语义控件；以 Tab、Enter/Space 切章并验证当前章提示与阅读内容 |
| 阅读主题只能指针操作 | 主题色块是绑定点击事件的 `<span>` | 键盘无法正常选择主题，选中状态缺少明确语义 | 使用按钮等原生交互元素，提供主题名称和选中状态；键盘切换后刷新确认偏好保留 |
| 损坏阅读偏好导致初始化异常 | `Reader.vue` 在初始化 `reactive` 时直接 `JSON.parse(localStorage...)`，无异常恢复；主题键也直接用于主题查找 | 无效本地存储可能阻断阅读页面初始化 | 安全解析及字段校验，非法值回退默认；覆盖损坏 JSON、错误类型、未知主题和越界数值；原章节正文保持不变 |
| 世界观初始右侧无引导 | `worlds.txt` 初始仅显示新建入口；`Worlds.vue` 右侧只有 `v-if="cur"`，未选择时没有替代内容 | 右侧大片空白，用户不清楚下一步 | 添加选择/创建引导，保留已有世界观隔离及保存逻辑；分别检查空库、有列表未选择、新建草稿状态 |
| 提示词初始右侧无引导 | `prompts.txt` 初始只有搜索与新建入口；`Prompts.vue` 右侧同样仅在 `cur` 存在时渲染 | 缺少录入和手动图片对比入口说明 | 添加适当空状态，不暗示未配置的生图服务可用；创建、保存、重新选择后可继续原有流程 |

提示词主布局也使用固定 `300px 1fr`。这是源码确认的窄屏风险，尚不能用收藏集的实际复现替代提示词自身的完整交互复测。收藏集拖动排序、封面与移出操作，以及世界观标签切换等仍存在需继续审查的指针交互；本轮不能由上述小修推导出全站键盘可访问性达标。
