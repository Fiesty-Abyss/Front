# PR A：分页、流式写入与持久任务

2026-10-18；叠加在尚未合并的 PR #11 审计分支上。正式版本仍为 v0.6.4。

## 完成范围

- 素材画廊每页 60 项，支持上一页、下一页、末页和筛选回到首页；过期响应不覆盖新结果。列表 SQL 不加载正文，详情仍返回完整已保存正文。
- 上传与本机目录导入共用 1 MiB 分块哈希、大小限制、临时文件和原子文件落盘；新路径用完整 SHA256，兼容旧路径。缩略图从文件读取。模型文件夹 ZIP 写磁盘临时文件，不再在内存拼整包。
- 大文本预览上限 4 MiB，显式提示，原文件保留完整；超过 32 MiB 的部分整文件解析器返回延后分析说明。这不代表完整预览大模型或大 Office 文件。
- 两个按需创建的 worker，最多另排队 32 项，满队列返回 429；近 200 条终态历史和活动任务保留。SQLite 本地任务账本 `jobs.sqlite3` 独立于 `front.db`，防止进度写入等待同一 worker 的主数据库事务。无新常驻服务或依赖。
- 重启将活动任务标记为 interrupted，保留检查点，不自动重放 AI 请求；导入界面恢复最近任务，离开页面停止轮询。取消在当前文件/操作完成后生效。
- 本机批量导入逐文件提交，可重新导入原目录并按哈希跳过重复内容。旧同步 API 保留兼容；新 UI 使用 `/api/import/jobs`。导入来源目录不修改、不删除。

## 尚未完成与风险

- 无自动断点续跑；最多约 250ms 的内存进度未到检查点时可能未持久化，素材提交仍独立保留。重试需选择原目录，不自动复制此前表单，也不自动复用新建作品；CG 重试应选择已创建的作品。
- 暂无按路径/mtime 指纹的增量免哈希扫描，重复导入仍读文件计算哈希；关联素材选择器仍有各自数量上限，本轮只修复主素材画廊。
- DB 事务与文件系统没有跨系统原子事务；数据库失败可能留下未引用的受管理文件，不自动清理。没有整库恢复或升级前备份保证。
- 取消不能中断当前解析器/网络调用；优雅退出需等待当前调用的超时。异常关闭后仅标记中断，不保证未提交工作恢复。
- 32 MiB 解析降级不是所有解析器的统一内存沙箱；图片解码、PDF 和 ZIP 条目仍须继续做资源限额。未测生产大库、独立进程 RSS、GPU、真实崩溃注入。
- Live2D Studio 实时渲染、面捕、Tauri、安装/便携版、签名更新和发布流水线仍未完成，不能将本轮称为 v0.7 发布。

真实模型后续验证采用用户最新限制：仅个人非商用、学习、桌宠、静态截图；禁止直播、商用、二次发布/倒卖/修改模型牟利与虚拟主播活动。只读源目录，不把第三方素材提交 Git。作者与来源归档在模型档案阶段完成，截图发布需再核对授权与署名。
