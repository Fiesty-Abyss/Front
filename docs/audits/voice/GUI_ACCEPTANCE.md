# Voice Studio 实际浏览器验收 · 2026-11-08

环境：本机 Windows，Python 3.12 源码 Sidecar、生产 Vue 构建、IAB Chromium。完全独立的数据目录、随机回环端口与本实例访问令牌；未连接个人资料库、TTS、GPU 推理或收费 API。音频是生成的 2 秒/16 kHz/单声道 PCM 正弦测试音，不含真人声音，不代表真实 TTS 或音质验收。

## 实际流程

- 在页面新建声线，关联虚构 OC/角色、模型登记（无权重的生成占位文件）、中文语言及已有试听素材；保存并查看版本。
- 新建世界观配音工程；新增、修改、拆分、排序、合并台词。拆并前 3 个片段仍可查看，旧版本不删除。
- 关联 2 个手动 WAV 候选、试听、切换与采纳。浏览器 audio 元素实际进入播放状态；换候选创建新播放器，离开页面 audio 元素数为 0。
- 从页面预览、确认导出并下载 ZIP；实际校验 ZIP CRC、32000 帧/16 kHz WAV、2 秒片段字幕、SRT/VTT 和来源清单。手动生成音不标为 AI 合成。
- 关闭并重新启动自有隔离服务两次，核对工程/声线稳定身份、文本、保留片段、2 个候选和导出记录一致。
- 键盘 Tab 从文本域经过语言、速度到保存按钮，Enter 提交成功。390×844 窄屏与默认桌面布局均实际检查。

## 发现与修复

| 实际问题 | 修复及复验 |
| --- | --- |
| 刷新工程静默丢弃未保存文本 | 保留独立草稿及原片段版本；离开/切换前确认，显式重载才放弃。实际取消离开后草稿仍在 |
| 刷新工程使导出历史变成 0 | 用稳定的工程/版本/有序片段上下文监听；同工程保留并重载小型分页历史，切换工程才清空 |
| 390 px 视口正文横向溢出至 480 px | 片段按钮允许换行；修复后 document clientWidth=380、scrollWidth=380 |
| 编辑已有台词时不存在的声线触发 ORM 自动 flush 外键异常/500 | 在修改 ORM 对象前校验声线；页面明确显示不存在，API 返回 404，回归保证文本与版本均未变 |

并发复验：另一独立 API 客户端先保存；GUI 旧草稿保存被拒绝，刷新保留草稿和旧片段版本，再保存仍被拒绝，不悄悄覆盖。用户明确重载后读取新的保存版本。导出历史经刷新与工程版本改变仍存在。修复后控制台检查无未捕获 JS 错误；负向 API 测试的 404/409 是预期结果。

## 性能与限制

没有新运行依赖、数据库字段或轮询器；刷新只请求既有分页元数据，不读取音频原件。5 次素材/Voice 切换后 audio DOM 为 0；后端短时工作集从 113.17 到 114.02 MiB、PrivateBytes 从 97.51 到 98.17 MiB，句柄数 181→197 后保持。该短样本不是前端 Heap/GPU/整机内存或无泄漏结论。

本分支本机 396 后端测试、15 前端测试及生产构建通过。Windows 原生窗口、干净安装/升级、长时间硬件与真实 TTS 仍未验收；Windows Actions 构建也不替代这些场景。截图只含虚构角色与生成素材，不含个人/第三方模型。
